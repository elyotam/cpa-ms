# M-website · משה שטרן, רואה חשבון

שדרוג מלא לאתר cpa-ms.com. עשרה עמודים בעברית RTL.
אתר סטטי: HTML, CSS ו־JavaScript רגילים שרצים ישירות בדפדפן, בלי framework
ובלי תלויות זמן ריצה. הדבר היחיד שנטען מבחוץ הוא הגופנים ושתי ספריות אנימציה,
ובלעדיהן האתר עדיין עובד — הוא פשוט מפסיק להיות סרט.

---

## קישורים

* **אתר חי לצפייה:** https://elyotam.github.io/cpa-ms/
* **קוד:** https://github.com/elyotam/cpa-ms

האתר החי מוגש מ־GitHub Pages מענף `main`. כל דחיפה ל־`main` מפרסמת מחדש
תוך דקה או שתיים. הקנוניקל בכל עמוד מצביע על `www.cpa-ms.com`, כדי
שגרסת התצוגה לא תתחרה בדומיין האמיתי בתוצאות החיפוש.

## איך מריצים

```bash
cd M-website
npm run serve        # שרת סטטי קטן, http://localhost:4321
```

או `npm start` כדי לבנות ואז להריץ.

> תיקיית `node_modules` נוצרת רק לכלי הבדיקה (puppeteer-core).
> האתר עצמו לא צריך אותה — אפשר למחוק בלי לשבור כלום.

## איך מעדכנים תוכן

**אף פעם לא עורכים את קבצי ה־HTML בשורש.** הם נבנים.

התוכן של כל עמוד יושב ב־`src/<שם>.body.html` — רק הגוף.
התפריט, הפוטר, ה־`<head>`, רצועת הסיום ורשימת הסקריפטים מוגדרים פעם אחת ב־`build.js`.

```bash
node build.js
```

הפקודה בונה מחדש את עשרת העמודים, וגם `sitemap.xml` ו־`robots.txt`.
כך שינוי בתפריט או במספר הטלפון נעשה במקום אחד ומתעדכן בכל האתר.
פרטי הקשר מרוכזים באובייקט `SITE` בראש `build.js`.

## מה בנוי מתחת למכסה המנוע

### שפת העיצוב

ברירת המחדל היא **נייר**, לא דיו: רקע חם בהיר, כחול הנייבי של הלוגו כצבע
מבטא יחיד, וטיפוגרפיה גדולה. ה־hero, מקטע המכשיר ורצועת הסיום נשארים כהים —
דף בהיר עם hero כהה היא התבנית של משרדים מקצועיים.

מה שהוסר במכוון: מסך טעינה, גריין, סמן מותאם, כפתורים מגנטיים, מספרי רקע
בכרטיסים, מרקיזת מילות מפתח, מקטע קולנוע נעוץ באורך שלושה מסכים, וגלילה
אופקית נעוצה. כל אלה קראו כמו סטודיו יצירתי ולא כמו רואה חשבון.

### scene.js — המנוע התלת־ממדי

Raymarcher שנכתב מאפס ב־WebGL2, בלי Three.js ובלי שום ספרייה.
שלושה מטבעות זהב מלוטשים עם שוליים מחורצים ופנים מגולפות, ממוזגים ב־smooth
minimum, מוארים בסביבת סטודיו פרוצדורלית עם צללים רכים ו־ambient occlusion.
אין מודלים, אין טקסטורות, אין קבצים — הכול מחושב פר־פיקסל.

`window.Bullion.create(canvas, opts)` מייצר מופע. האתר מריץ שניים:
אחד ב־hero ואחד בסקשן הסרט. כל מופע עוצר את עצמו כשהוא יוצא מהמסך או
כשהטאב לא פעיל, ומוריד רזולוציה אוטומטית אם ה־GPU לא עומד בקצב.

בלי WebGL2 נכנס `hero.js` — סצנת canvas דו־ממדית שמספרת את אותו סיפור.

> **RTL:** הטקסט יושב מימין, ולכן הפסל מוזז שמאלה (`shift` שלילי).

### motion.js — שכבת הגלילה

Lenis לגלילה אינרציאלית, GSAP ScrollTrigger לשאר:

* **הסרט** (`#reel`) — סקשן נעוץ שבו מצלמת ה־WebGL מבצעת תנועה אמיתית תוך כדי
  גלילה, עם שלוש כותרות שמתחלפות ופס התקדמות. זה ה"וידאו" של האתר,
  רק שהוא מרונדר חי ולא קובץ.
* **המסע** (`#journey`) — מסלול אופקי נעוץ. ב־RTL הוא חייב לנוע בכיוון x **חיובי**,
  כי הרצועה מתחילה צמודה לימין וגולשת שמאלה.
* פרלקסה, חשיפות מקובצות, והכול מכבד `prefers-reduced-motion`.

שניהם מושבתים מתחת ל־860px, שם הסקשנים נערמים לגובה.

### הנכסים של המשרד

הלוגו, התמונות והסרטונים נלקחו מהאתר החי של המשרד (cpa-ms.com) ועברו עיבוד:

```bash
node tools/harvest.js        # מרנדר את עמודי האתר החי ומוריד כל מדיה שהוא טוען
node tools/optimize.js       # מקטין ומקודד ל-webp, ומחלץ poster לכל סרטון
node tools/shrink-video.js   # מקודד מחדש את סרטוני הרקע דרך MediaRecorder
node tools/favicon.js        # בונה favicon מהסמל של המשרד
```

* **לוגו** — `logo.png` המלא ו־`logo-mark.png` (סמל ה־MS בלבד, לתפריט).
  הסמל הוא אמנות כחולה, ולכן הוא מתהפך ללבן על רקע דיו ונשאר כחול על נייר.
* **פורטרט** — `moshe.jpg`, התמונה מעמוד אודות באתר המקורי.
* **צילומים** — 16 תמונות עסקיות. עברו גרייד אחיד (הפחתת רוויה + נטייה חמה)
  כדי שיישבו בתוך פלטת הדיו והפליז, וחוזרות לצבע מלא ב־hover.
* **אייקונים** — סט האייקונים של המשרד עצמו, ממוסך ל־CSS כדי לקבל את צבע הפליז.
* **סרטונים** — 9 קבצים. שניים משמשים רקע (`brand-a/b`, קודדו מחדש מ־6.6MB ל־0.5MB)
  ושבעה הם המלצות לקוחות שנטענות רק בלחיצה.
* **סמלי רשויות** — רשות המסים, בנק ישראל וביטוח לאומי, על צ׳יפ לבן.

המקורות ברזולוציה מלאה נשמרים ב־`tools/harvest/` (כ־135MB). התיקייה אינה חלק
מהאתר ואינה נכנסת ל־git — היא שם רק כדי שאפשר יהיה לגזור מחדש נכסים.

### assets/img — האמנות שנוצרה

21 קבצים שנוצרו אלגוריתמית. `node tools/genart.js` פותח את `tools/art.html`
בדפדפן headless ומצלם כל קומפוזיציה ל־webp:

| מוטיב | איפה |
|---|---|
| `flow` — שדה זרימה | מסחר אלקטרוני, ספוטלייט |
| `strata` — שכבות | חברה בע״מ |
| `ledger` — שורות ורישומים | עוסק מורשה |
| `rings` — טבעות טופוגרפיות | עוסק פטור, פלטת פורטרט |
| `cells` — רשת צמתים | מטבעות דיגיטליים |
| `weave` — קצב אחיד | לשכת שכר |
| `spiral` — פילוטקסיס | שותפות, כותרות עמודים |
| `wave` — צמיחה | תהליך, תמונת שיתוף |

לשלושה רקעים יש גם גרסת נייר (`-l`) למצב הבהיר, כי אמנות כהה על רקע קרם
נהפכת לאפור. הרצה מחדש נדרשת רק כששפת העיצוב משתנה.

### calc.js — המחשבונים

שני מחשבונים על מנוע אחד: **נטו לעצמאי** ו**השוואת מסלולים**
(עוסק פטור מול מורשה מול חברה), כולל מע״מ תשומות שעוסק פטור לא מקזז,
מס חברות, מס דיבידנד ומס יסף. כל החישוב רץ בדפדפן ושום נתון לא נשלח לשרת.

נתוני 2026 מרוכזים באובייקט `DATA` בראש הקובץ — **זה המקום היחיד לעדכון שנתי**:
מדרגות 10%–47% ומס יסף 3%, נקודת זיכוי 242 ₪, תקרת עוסק פטור 122,833 ₪,
ביטוח לאומי 7.7% ו־18%, מס חברות 23%, מס דיבידנד 30%, מע״מ 18%.

## כלי הבדיקה

```bash
node tools/qa.js            # סריקת כל העמודים: שגיאות JS, גלישה, תמונות שבורות
node tools/qa.js mobile     # אותו דבר ב-390px
node tools/qa.js light      # אותו דבר במצב בהיר
node tools/contrast.js      # ביקורת ניגודיות WCAG AA, עשרה עמודים כפול שני מצבים
node tools/perf.js          # משקל עמוד וזמני צביעה
node tools/overflow.js      # גלישה אופקית ב-390px, כל העמודים
node tools/keys.js          # סדר טאב, מיקוד גלוי, התנהגות המגירה
node tools/shot.js '[...]'  # צילומי מסך, תומך בגלילה לסלקטור
node tools/genart.js        # ייצור מחדש של קבצי האמנות
```

`contrast.js` יודע על האזורים שכהים בשני המצבים (hero, כותרות עמודים,
התפריט לפני שהוא מתמצק, הסרט ורצועת הסיום) ומודד מולם, אחרת הוא היה
מדווח על עשרות כשלים מדומים.

**מצב נוכחי:** עשרת העמודים נקיים בשלושת המצבים, ואפס כשלי ניגודיות.

## נגישות

`dir="rtl"`, מבנה סמנטי, דילוג לתוכן, ניווט מקלדת מלא עם `focus-visible`,
`aria-*` על כל הרכיבים האינטראקטיביים, כיבוד `prefers-reduced-motion`,
וווידג׳ט עם שישה מצבים (גודל טקסט, ניגודיות, הדגשת קישורים, גופן קריא,
עצירת אנימציות, איפוס) שנשמרים בין ביקורים. הצהרת הנגישות לפי ת״י 5568.

## SEO

`<title>` ותיאור ייחודיים לכל עמוד, canonical, Open Graph עם תמונת שיתוף,
JSON-LD מסוג `AccountingService`, sitemap ו־robots.

## הטופס

אין שרת, ולכן הטופס לא שולח לשום מקום. אחרי ולידציה מלאה בעברית הוא בונה
הודעת וואטסאפ מוכנה עם כל הפרטים ופותח אותה במכשיר של הפונה.
מעבר לשליחה בדוא״ל הוא שינוי של כמה שורות ב־`app.js` מול Formspree או דומיו.

  דרך לדעת מי מדבר בכל אחד. עם רשימה מסודרת אפשר להוסיף שם ותפקיד לכל אחד.
* **גיבוי דוא״ל לטופס**, אם רוצים משהו מעבר לוואטסאפ.
* **אימות תקרת ההכנסה המבוטחת בביטוח לאומי ל־2026**, שמופיעה כאומדן.
* **פרטי רכז נגישות רשמיים** בהצהרת הנגישות.
