# cpa.ms · משה שטרן, רואה חשבון

שדרוג מלא לאתר cpa-ms.com. אחד עשר עמודים בעברית RTL.
אתר סטטי: HTML, CSS ו־JavaScript רגילים שרצים ישירות בדפדפן, בלי framework
ובלי תלויות זמן ריצה. הדבר היחיד שנטען מבחוץ הוא הגופנים ושתי ספריות אנימציה,
ובלעדיהן האתר עדיין עובד — הוא פשוט מפסיק לזוז.

---

## קישורים

* **אתר חי לצפייה:** https://elyotam.github.io/cpa-ms/
* **קוד:** https://github.com/elyotam/cpa-ms

האתר החי מוגש מ־GitHub Pages מענף `main`. כל דחיפה ל־`main` מפרסמת מחדש
תוך דקה או שתיים. הקנוניקל בכל עמוד מצביע על `www.cpa-ms.com`, כדי
שגרסת התצוגה לא תתחרה בדומיין האמיתי בתוצאות החיפוש.

**גיבוי:** יש תג אחד, `v1`, ו־Release תואם. שחזור מלא הוא `git checkout v1`.

## איך מריצים

```bash
cd cpa.ms
npm run serve        # שרת סטטי קטן, http://localhost:4321
```

או `npm start` כדי לבנות ואז להריץ.

> תיקיית `node_modules` נוצרת רק לכלי הבדיקה (puppeteer-core).
> האתר עצמו לא צריך אותה — אפשר למחוק בלי לשבור כלום.

## איך מעדכנים תוכן

**אף פעם לא עורכים את קבצי ה־HTML בשורש.** הם נבנים.

התוכן של כל עמוד יושב ב־`src/<שם>.body.html` — רק הגוף.
התפריט, הפוטר, ה־`<head>`, רצועת הסיום ורשימת הסקריפטים מוגדרים פעם אחת ב־`build.js`.

```bash
node build.js
```

הפקודה בונה מחדש את אחד עשר העמודים, וגם `sitemap.xml` ו־`robots.txt`.
כך שינוי בתפריט או במספר הטלפון נעשה במקום אחד ומתעדכן בכל האתר.
פרטי הקשר מרוכזים באובייקט `SITE` בראש `build.js`.

## מה בנוי מתחת למכסה המנוע

### שפת העיצוב

ברירת המחדל היא **דיו**: לוח מחוונים כהה. המצב הבהיר קיים ככפתור, לא כברירת מחדל.
הצבע המבטא הוא כחול במתח מלא `#3D8BFF` — הפלדה של הלוגו, מוגברת — ולצידו
ירוק סיגנל `#3DDC97` ששמור **רק למה שחיובי**: הסכום שנשאר בכיס, הקצה המוביל
של הגרף, תגי השינוי. סגול `#7A6BFF` מופיע בגרדיאנטים בלבד.

הדף לא שוכב שטוח: להירו יש שלושה כתמי אור שנודדים לאט, לכל רצועה יש מקור
אור משלה, ומאחורי כל העמודים יש שטיפה קבועה כדי שגלילה ארוכה לא תיפול לשחור.

מה שהוסר במכוון: מסך טעינה, גריין, סמן מותאם, מספרי רקע בכרטיסים, מרקיזת
מילות מפתח, מקטע קולנוע נעוץ באורך שלושה מסכים, וגלילה אופקית נעוצה.
כל אלה קראו כמו סטודיו יצירתי ולא כמו רואה חשבון.

### ledger.js — הגיליון

canvas דו־ממדי, בלי WebGL. גיליון מסורגל עם ציר ערך בשקלים וסימוני שנים,
עמודות מחזור רבעוניות מאחורי עקומת צמיחה מונוטונית־קובית, שלוש שכבות זוהר,
קו שרץ מכחול עמוק בתחילתו לירוק בקצה המוביל, ומחוון שסורק את הקו ומדפיס
את הסכום שמתחתיו. הנקודה המובילה שומרת פעימה איטית כדי שהגיליון ייקרא כחי
ולא כמודפס.

`window.Ledger.create(canvas, opts)` מייצר מופע. האתר מריץ שניים: אחד בהירו
ואחד בסקשן הגיליון, שם `mode:'reel'` מפזר קריאות לא מותאמות שמתכנסות אל הקו
תוך כדי גלילה — בדיוק מה שהכיתובים אומרים. כל מופע עוצר את עצמו כשהוא יוצא
מהמסך או כשהטאב לא פעיל.

הקנבס **לא** צובע לעצמו רקע אטום, אחרת הוא היה אוטם את האור שמתחתיו.

> **RTL:** הטקסט יושב מימין, ולכן שטח הציור נדחק שמאלה. האור והחלוניות
> ממוקמים ב־`left`/`right` פיזיים בכוונה — תכונות לוגיות היו מעיפות אותם
> אל מתחת לטקסט.

זה החליף שני ניסיונות קודמים: מטבעות זהב מרחפים אמרו *כסף*, לא *מדידה*.
פסל טבעות מרואימרצ׳ד אמר *ג׳ירוסקופ*. הלקח שנשאר: **החומר של המשרד הוא
מספרים, ולכן ההירו צריך לצייר מספרים.**

### motion.js — שכבת הגלילה

Lenis לגלילה אינרציאלית, GSAP ScrollTrigger לשאר: חשיפות מקובצות, פרלקסה,
והתכנסות הקריאות בסקשן הגיליון. הכול מכבד `prefers-reduced-motion`.

ארבעת שלבי התהליך הם רשת בכל רוחב מסך — המסלול האופקי הנעוץ הוצא.

### הנכסים של המשרד

הלוגו, התמונות והסרטונים נלקחו מהאתר החי של המשרד (cpa-ms.com) ועברו עיבוד:

```bash
node tools/harvest.js        # מרנדר את עמודי האתר החי ומוריד כל מדיה שהוא טוען
node tools/optimize.js       # מקטין ומקודד ל-webp, ומחלץ poster לכל סרטון
node tools/shrink-video.js   # מקודד מחדש סרטונים דרך MediaRecorder
node tools/favicon.js        # בונה favicon מהסמל של המשרד
```

* **לוגו** — `logo.png` המלא ו־`logo-mark.png` (סמל ה־MS בלבד, לתפריט).
  הסמל הוא אמנות כחולה, ולכן הוא מתהפך ללבן על רקע דיו ונשאר כחול על נייר.
* **פורטרט** — `moshe.jpg`, התמונה מעמוד אודות באתר המקורי.
* **צילומים** — 16 תמונות עסקיות, בגרייד קריר שמתיישב עם הקונסולה
  וחוזר לצבע מלא ב־hover.
* **אייקונים** — סט האייקונים של המשרד עצמו, ממוסך ל־CSS כדי לקבל את צבע המבטא.
* **סרטונים** — שבעה, וכולם המלצות לקוחות שנטענות רק בלחיצה. שתי לקטות
  הסטוק שהיו כאן (ים והר מושלג) הוסרו: הן אמרו "רוגע" באופן כללי ולא אמרו
  כלום על רואה חשבון.
* **סמלי רשויות** — רשות המסים, בנק ישראל וביטוח לאומי, על צ׳יפ לבן.

המקורות ברזולוציה מלאה נשמרים ב־`tools/harvest/` (כ־135MB). התיקייה אינה חלק
מהאתר ואינה נכנסת ל־git — היא שם רק כדי שאפשר יהיה לגזור מחדש נכסים.

### assets/img — האמנות שנוצרה

קבצים שנוצרו אלגוריתמית. `node tools/genart.js` פותח את `tools/art.html`
בדפדפן headless ומצלם כל קומפוזיציה ל־webp:

| מוטיב | איפה |
|---|---|
| `flow` — שדה זרימה | מסחר אלקטרוני, ספוטלייט |
| `strata` — שכבות | חברה בע״מ |
| `ledger` — שורות ורישומים | עוסק מורשה |
| `rings` — טבעות טופוגרפיות | עוסק פטור, פלטת פורטרט |
| `cells` — רשת צמתים | מטבעות דיגיטליים |
| `weave` — קצב אחיד | לשכת שכר |
| `spiral` — פילוטקסיס | שותפות, כותרות עמודים |

לשלושה רקעים יש גם גרסת נייר (`-l`) למצב הבהיר, כי אמנות כהה על רקע קרם
נהפכת לאפור. הרצה מחדש נדרשת רק כששפת העיצוב משתנה.

### calc.js — המחשבונים

שלושה מחשבונים על מנוע אחד: **נטו לעצמאי**, **השוואת מסלולים**
(עוסק פטור מול מורשה מול חברה) ו**ביטוח לאומי לעצמאי** לפי רווח שנתי או חודשי.
ההשוואה כוללת מע״מ תשומות שעוסק פטור לא מקזז, מס חברות, מס דיבידנד ומס יסף,
ומתחשבת בשאלה אם הלקוחות הם עסקים או צרכנים פרטיים — בלי זה עוסק פטור
לעולם לא היה יכול לנצח. כל החישוב רץ בדפדפן ושום נתון לא נשלח לשרת.

נתוני 2026 מרוכזים באובייקט `DATA` בראש הקובץ — **זה המקום היחיד לעדכון שנתי**:
מדרגות 10%–47% ומס יסף 3%, נקודת זיכוי 242 ₪, תקרת עוסק פטור 122,833 ₪,
מס חברות 23%, מס דיבידנד 30%, מע״מ 18%, וביטוח לאומי לעצמאי 7.7% על החלק
שעד 7,703 ₪ לחודש ו־18% מעליו.

**התקרות והשיעורים אומתו** מול
[לוח השיעורים לעצמאים של הביטוח הלאומי](https://www.btl.gov.il/Insurance/Rates/Pages/%D7%9C%D7%A2%D7%A6%D7%9E%D7%90%D7%99%D7%9D.aspx),
נכון ל־1.1.2026: תקרת הכנסה מבוטחת 51,910 ₪ לחודש, מדרגה ראשונה 4.47% ביטוח
לאומי ועוד 3.23% בריאות, מדרגה שנייה 12.83% ועוד 5.17%. הטבלאות באתר מציגות
את הפירוק הזה ואת תאריך התחולה. השיעורים עצמם הם נתון רשמי; רק **תוצאות**
המחשבונים מסומנות כאומדן, כי הן מניחות מודל מפושט.

## כלי הבדיקה

```bash
node tools/qa.js            # סריקת כל העמודים: שגיאות JS, גלישה, תמונות שבורות
node tools/qa.js mobile     # אותו דבר ב-390px
node tools/qa.js light      # אותו דבר במצב בהיר
node tools/contrast.js      # ביקורת ניגודיות WCAG AA, 11 עמודים כפול שני מצבים
node tools/perf.js          # משקל עמוד וזמני צביעה
node tools/overflow.js      # גלישה אופקית ב-390px, כל העמודים
node tools/keys.js          # סדר טאב, מיקוד גלוי, התנהגות המגירה
node tools/shot.js '[...]'  # צילומי מסך, תומך בגלילה לסלקטור
node tools/genart.js        # ייצור מחדש של קבצי האמנות
```

`contrast.js` יודע על האזורים שכהים בשני המצבים (הירו, כותרות עמודים,
התפריט לפני שהוא מתמצק, מקטע "שקט" ורצועת הסיום) ומודד מולם, אחרת הוא היה
מדווח על עשרות כשלים מדומים.

> **הערה על headless:** כרום ללא ממשק מדווח `prefers-reduced-motion: reduce`
> כברירת מחדל. בדיקה של אפקט hover שכולל תנועה חייבת
> `emulateMediaFeatures([{name:'prefers-reduced-motion', value:'no-preference'}])`,
> אחרת התנועה תיראה כאילו היא לא עובדת.

**מצב נוכחי:** אחד עשר העמודים נקיים בדסקטופ ובנייד, אפס כשלי ניגודיות, מקלדת נקייה.

## נגישות

`dir="rtl"`, מבנה סמנטי, דילוג לתוכן, ניווט מקלדת מלא עם `focus-visible`,
`aria-*` על כל הרכיבים האינטראקטיביים, כיבוד `prefers-reduced-motion`,
וווידג׳ט עם שישה מצבים (גודל טקסט, ניגודיות, הדגשת קישורים, גופן קריא,
עצירת אנימציות, איפוס) שנשמרים בין ביקורים.

הצהרת הנגישות לפי ת״י 5568 (WCAG 2.0 רמה AA), ונבדקה גם מול קריטריוני
WCAG 2.1 רמה AA. היא נושאת את פרטי רכז הנגישות הרשמיים כפי שהם מופיעים
באתר החי — משה שטרן, 054-4966495, moshe@cpa-ms.com, שמעיה 4 אלעד — ובנוסף
תאריך עדכון מפורש והתחייבות למענה תוך שני ימי עסקים.

## מה נשאר פתוח

* **לאשר מי בתמונה** — `moshe.jpg` נלקחה מעמוד אודות באתר המקורי. באתר החי יש
  גם דיוקן שני בעמוד הבית, של אדם אחר. אם התחלפו, זו החלפה של קובץ אחד.
* **שמות בהמלצות** — שבעת הסרטונים מסומנים כרגע ״המלצת לקוח״ בלי שם, כי אין
  דרך לדעת מי מדבר בכל אחד. עם רשימה מסודרת אפשר להוסיף שם ותפקיד לכל אחד.
* **גיבוי דוא״ל לטופס**, אם רוצים משהו מעבר לוואטסאפ.
* **שנת הרישיון** — האתר אומר "רישיון משנת 2015", והמדד בהירו אומר
  "12+ שנות רישיון". 2026 פחות 2015 הוא 11. אחד מהשניים צריך לתקן.
